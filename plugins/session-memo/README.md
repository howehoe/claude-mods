# session-memo

Claude Code のセッションごとに TODO とメモを残す mod です。中身は Markdown ファイルとして保存され、プロンプトの上に件数が出て、ペインで一覧・追加・チェック・削除ができます。
参考URL　https://zenn.dev/yesodco/articles/da634d752874b2#%E4%BD%9C%E3%81%A3%E3%81%9F%E3%82%82%E3%81%AE%E3%80%8Csession-memo%E3%80%8D

## インストール

ターミナル版 Claude Code のプロンプトで実行します:

```
/plugin install session-memo --marketplace howehoe/claude-mods
```

`Add marketplace?` に `y`、スコープを選べば有効になります(再起動は不要)。

## 使い方

### コマンド

| コマンド | 動作 |
| --- | --- |
| `/memo` | メモのペインを開く |
| `/memo <テキスト>` | メモを1件追加 |
| `/memo todo <テキスト>` | TODO を1件追加 |
| `/memo raw` | 保存先の `.md` ファイルをテキストエディタで開く |

改行を含むテキストは1行にまとめて保存されます。

### プロンプト上のバンド

プロンプトの上に常に次の1行が出ます。

```
memo: TODO 2/5 · メモ 3  [メモを開く] [mdファイルで開く]
```

`TODO 未完了数/総数` とメモの件数です。ボタンからペインや `.md` ファイルを開けます。

### ペイン

- **TODO**: `[ ]` / `[x]` を押すと完了を切り替え、`削除` で消去。下の入力欄で追加
- **メモ**: `削除` で消去、下の入力欄で追記
- 先頭に保存先のパスが表示されます

モバイルでは入力欄が出ないので、追加は `/memo` コマンドで行ってください。

## 保存先

Claude Code を起動したディレクトリの下に、セッションごとに1ファイル作られます。

```
.session-memo/<セッションID>.md
```

```markdown
# Session memo <セッションID>

## TODO
- [ ] まだのタスク
- [x] 終わったタスク

## Memo
- メモ
```

- ファイルを直接編集しても、3秒以内にバンドとペインに反映されます
- 読み込むのは `## TODO` の下の `- [ ]` / `- [x]` 行と、`## Memo`(または `## メモ`)の下の `- ` 行です
- リポジトリ内で使う場合は `.gitignore` に `.session-memo/` を追加しておくのがおすすめです

## 動作環境

- `/memo raw` は macOS では `open -t`、それ以外では `xdg-open` でファイルを開きます
