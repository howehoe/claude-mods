# claude-mods

Claude Code 用の mod 集です。

## インストール

ターミナル版 Claude Code のプロンプトで実行してください:

```
/plugin install session-memo --marketplace howehoe/claude-mods
```

`Add marketplace?` で `y` を押し、スコープを選びます(通常は user)。

## Mods

| 名前 | 内容 |
| --- | --- |
| session-memo | セッションごとの TODO / メモを Markdown で保持。プロンプト上のバンドと `/memo` ペイン |
